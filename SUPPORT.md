# Support

Use GitHub Issues for reproducible bugs and feature requests. Use Discussions for usage questions,
format proposals, and integration examples once Discussions is enabled.

Before opening an issue, include the L10n Sentinel version, Python version, operating system,
command, smallest redistributable fixture, actual output, and expected output. Remove confidential
or customer content first.

The project is maintained on a best-effort basis and does not currently provide paid support or a
service-level agreement. Security reports must use the private process in [SECURITY.md](SECURITY.md).
