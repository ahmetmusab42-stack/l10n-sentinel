# Governance

L10n Sentinel currently uses a single-maintainer model. The primary maintainer is
[Ahmet Ercan](https://github.com/ahmetmusab42-stack), who owns release,
security, and roadmap decisions and is expected to document decisions in issues or pull requests.

Contributors who demonstrate sustained, constructive participation may receive triage and then
write access. Access is granted for project work, reviewed periodically, and removed when it is no
longer needed. No maintainer status, endorsement, or program benefit can be bought or exchanged.

Changes to parsing, severity, exit codes, report schemas, and release automation require tests and
maintainer review. Security reports follow [SECURITY.md](SECURITY.md).
